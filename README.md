# Tic-Tac-Toe 🎮

A modern, feature-rich Tic-Tac-Toe game built with **React** and **Vite**.

## 🎯 Features

- ✅ Two-player mode (X vs O)
- ✅ Win detection with animated line
- ✅ Blood splash effect for X wins
- ✅ Lightning effect for O wins
- ✅ Score tracking for both players
- ✅ Winning cells highlighted
- ✅ Reset button to start a new game
- ✅ Responsive design (works on mobile & desktop)
- ✅ Custom SVG icons with glow effect

## 🛠️ Tech Stack

- **React** — UI library
- **Vite** — Build tool
- **CSS3** — Styling & animations
- **SVG** — Custom animations and effects
- **JavaScript (ES6+)** — Logic

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm

# Install dependencies
npm install

# Run development server
npm run dev
